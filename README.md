## What this project is

This project is a game I made. The idea came from the GMTK game jam but I am not experienced enough to build a game in the short amount of time. Instead I took that theme and decided to make a game at my own pace.
up to this point I hadn't made a game before. I could never find the right idea but this one stuck. I made this game over many hours of trying and failing as this is my first finished game. This is the first of
many projects I hope to finish.

## How I made this
When choosing what to use I went with Godot because it isn't very resource heavy and can run well on my computer. Also because I heard it had an easier coding language then others. They were right. It was easy
for me to pickup and felt intuitive and nice. I will stick with it going forward. For this project I used my own art assets that I made in Libresprite because I haven't gotten Aesprite. I also used some of Kenny's assets
in this: https://kenney.nl/assets
